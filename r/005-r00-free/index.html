空岛改成照星露谷那样拼起来了，夜市也用同一座岛。改动全在 这一轮的文件夹 里，打开 index.html 就能玩。所有自动检查都是无头跑的，全部通过；有两处卡住是自动演示跑出来以后修掉的（见文末）。

这一轮的变化

  • 空岛是拼起来的，不是一整张图：地面用草地、石板路、泥地、木板四种图块铺，16 像素一格。前面的岛边和底下的岛底是单独一层。农舍、仓库、船坞、告示板、柜台、三个摊位、栈桥，以及每棵树、每段栅栏、每盏灯、木桶、长椅、灌木，都是从 资料/空岛零件/ 抠出来的透明零件，位置写在 game/isle_layout.js。原来那张整岛图在空岛上不再用。
  • 前后遮挡按零件轮廓，看不到方框：人、船、货箱和零件按脚底的位置排前后，零件透明的地方不挡人。侧墙往后退的房子和斜着的栅栏按列切开排，站在船坞侧墙后面时只有侧墙那几列挡你。
  • 半透明和剪影：树、房子、摊位、告示板、栈桥上的船挡住船长时淡到 42%；栅栏、灯柱这类矮东西挡住大半个人时，画一个淡淡的剪影。
  • 拉近也清楚：零件从源图直接缩到要的大小（船长 62 高、农舍 250 宽）。走动镜头一个零件像素就是画面一个像素，1920×1080 下是 3×3 个屏幕像素。走动和看全岛两套像素格各一套色板；按住 Tab 看全岛照旧。
  • 夜市在同一座岛：同一套零件载入时调暗、点灯（煤气灯、摊位和柜台的油灯、船坞的灯、亮着的窗户），夜里的颜色另算一套色板。人和船走到灯下会亮起来。
  • 描边：沿零件自己的形状描金边，走近了或者该去的那个照旧一闪一闪。
  • 镜头和流畅度保留：上一步的跟随镜头、按住 Tab、画面顺都还在。走动时画面里看得到岛宽的约 41%（以前 38%）。

检查结果

  • 自动演示（tools/demo.mjs 8 6 6）：约 48 分钟游戏时间，玩完一整局 6 天又进了第二局，0 次卡住、0 个错误，每晚 0 人走掉。改完画法后又跑了 4 分钟，也是 0 卡住、0 错误。
  • 4K 画布（1920×1080、两倍像素密度）：每一屏稳 60 帧。空岛和夜市主线程占用从每帧逐个画零件时的 92–95% 降到 43%，办法是载入时把地面和零件烘成一层，每帧只重画要盖在人身上的零件。
  • 从标题玩到第二天早上约 1 万帧，只有刚载入时标题第一帧一次长任务（约 110 毫秒）。
  • soak 乱按 0 个错误；full / order / beast / down / chase / dock / heat 都走通；三晚夜市 0 人走掉；演示开关检查全部 OK。
  • 截图 截图/00–17 重拍了，18–26 是新岛：躲在树后面树变透明、告示板按轮廓挡住、栈桥上的船后面、按住 Tab 看全岛、夜市摊位后面、夜市柜台和灯光等。

自己定的几件事（都写在 notes.md 假设 42–56）

  • 世界尺寸定为 1920×1080，正好是原来逻辑坐标的 3 倍，所以玩法数值都不用改。
  • 集市 1 级岛上只摆 3 个摊位；橙、紫两个是绿、蓝摊位换色做的，升级集市后才出现。伙计屋和配货台的零件已经构建好，但岛上不摆，因为这一段没有伙计和招牌货。
  • 所有站位按新岛重新摆了：摊位离柜台 28 / 54 / 54（以前 22 / 47 / 56）；客人从栈桥走到柜台的路长 249，比以前（273）短一成，客人走路速度没改。
  • 走路一帧走得远时分小步走，不会一步跨过细栅栏。这是因为自动演示第一次跑时在 6 倍快进下从斜栅栏缝里钻进菜地出不来；缝也堵上了。另一处卡住是机器人顶在灌木角上蹭，改了测试工具的找路。

已知问题和占位

  • 地面路边是代码做的圆滑边，不是星露谷那种手画过渡图块。
  • 前崖面是同一张图左右重复，看全岛时能看出三道一样的瀑布。
  • 夜里的灯不闪。
  • 船长和客人还是只有左右两个朝向。
  • 建造模式还没做，但建筑现在都是零件了，可以做了。
